Step to execute :
1. Open IntelIJ or Download IntelIJ first
2. Open Project and waiting until project is fully loaded all dependencies
3. After dependencies fully loaded, click ctrl 2x
4. Typing **mvn clean test**
5. When project already done running, open target folder
6. Select **surefire-reports** folder, find **index.html** file
7. Right click on **index.html** file, hover to open in --> Browser --> Default/Chrome
